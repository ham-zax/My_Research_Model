For Route B, a draft version would be `E001-OBS-receipt-1` with `E001-OBS-label-1`. The retained measurement rule is the equal-weight Bybit/Binance BTC spot midquote at each local one-second receipt cutoff, each quote no more than five receipt seconds old; the same grid supplies triggers, decision features and labels. Preserve original exchange timestamps as diagnostics. A clock step creates a new epoch; reconnections, sequence gaps and snapshot resets invalidate the affected book/flow history. No later probe or later packet repairs an earlier decision. Labels start after the 15-second decision and remain unavailable through any required missing spot point before the first hit or horizon. Fitting waits until the entire prescribed horizon has elapsed.

The proposed observable model pair would keep only supported dimensionless shared inputs for B4 and add a **declared, contaminated observed-sell-pressure/capacity ratio** to MFSM. It would remove liquidation-pressure notional and any cancellation/execution attribution from the primary hypothesis. That changes the claim and the MFSM feature list; the exact eligible inputs, missingness rules, backlog threshold and evaluation protocol would be versioned before real scores. It must not inherit a `BTC_DEVELOPMENT_PASSED` result from the original experiment. The current synthetic +0.0241 Brier difference is irrelevant to this choice.

**Recommendation under a free-data constraint:** choose Route B only if the narrower observational question is acceptable. If the original source-age/liquidation mechanism is essential, choose Route A and first supply or fund an auditable provider contract. Neither route makes the six existing diagnostic decisions eligible. A qualified real capture must still fit within the existing 2026-09-25 00:19:49 UTC deadline and 16 GiB raw cap; any later acquisition period needs a separate instruction.
